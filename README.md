# Google IT Automation with Python

A collection of Python exercises and projects completed while working through Google's IT Automation with Python professional certificate coursework.

This repository documents hands-on learning, from Python fundamentals to practical automation projects. It includes small programming exercises, experiments with databases and interactive applications, and projects focused on automating real-world tasks.

## Projects

### Automation & Productivity

| Project | Description |

| [Automate Updating Catalog Information](./Automate-updating-catalog-information/) | Automates catalog information updates using Python. |

### Python Exercises & Challenges

The repository also includes smaller exercises covering programming fundamentals, problem-solving, and introductory database work.

- **Beginner exercises:** Adventure game, band name generator, BMI calculator, leap-year calculator, letter swap, life expectancy calculator, lunch bill roulette, password generator, rock-paper-scissors, and tip calculator.
- **Programming challenges:** Additional exercises collected in `Challenges.py`.
- **Probability calculator:** A project based on freeCodeCamp's probability calculator exercise.
- **MySQL exercise:** Introductory database work in `Intermediate_exercise_MySQL.py`.

## Skills & Concepts

- **Python:** Variables, data structures, control flow, functions, and problem-solving.
- **Automation:** File processing, image manipulation, report generation, and HTTP requests.
- **Application development:** Interactive command-line and terminal applications.
- **Databases:** Introductory SQL and MySQL.
- **Practical scripting:** Breaking problems into small, reusable programs and automating repetitive tasks.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/QuantumZenoSix/course-google-automation-with-python.git
cd course-google-automation-with-python
```

Individual exercises and projects have different dependencies and requirements. Review the relevant files before running them, and install any project-specific dependencies as needed.

For standalone Python scripts, a typical starting point is:

```bash
python3 path/to/script.py
```

Replace the example path with the script you want to run.
